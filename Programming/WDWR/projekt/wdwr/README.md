# WDWR — project working directory

Solver runs for the WDWR (decision support under risk) project. Everything
here is AMPL/CPLEX input and output rather than source.

| Path | What it is |
|---|---|
| `KRZYSZTOF_RUDNICKI_307585_WDWR_PROJEKT/` | The submitted bundle, kept exactly as handed in. |
| `KRZYSZTOF_RUDNICKI_307585_WDWR_PROJEKT.zip` | The same bundle, archived. |
| `old_data/` | Earlier data sets, superseded. |
| `result*.txt`, `solution*.txt` | Solver output for the model variants. |

The submitted directory duplicates files from its parent on purpose. It is a
record of what was submitted, so it is not de-duplicated.

The model and report live in `../doc/` and `../R/`.
