# EOPSY — lab 1: shell scripting

A shell-scripting exercise: recursively rename files and directories to
lower case, and drive `sed` over a tree.

| Path | What it is |
|---|---|
| `modify.sh` | The submitted solution. |
| `modify_examples.sh` | Worked examples used while developing it. |
| `A`, `b`, `RECURSEFILE`, `sed`, `recurselowerfile`, `LOWERCASEFOLDERMAIN`, ... | Fixture and result files. |

The oddly-named empty files are not junk and are not source: they are the
*output* of running the scripts, committed so the before/after state of the
exercise is visible. Their names are the point.
